## COMMENT_RULES.md

AI가 작성한 코드를 사람이 읽고 이해할 수 있도록 주석 작성 방식을 정한 규칙입니다.

### 핵심 규칙
- 코드를 그대로 읽어 주는 주석은 쓰지 않고, **"왜"** 이렇게 짰는지를 쓴다.
- **1줄**로 설명할 수 있으면 코드 안에 인라인 주석으로 쓴다.
- **2줄 이상** 필요하면 카테고리별 주석 파일에 쓰고, 코드에는 번호만 적는다.
- 변수의 역할은 길이와 관계없이 항상 변수(V) 주석 파일에 쓴다.

### 카테고리 (6개)

| 약자 | 카테고리 | 답하는 질문 | 주석 파일 |
|---|---|---|---|
| F | 실행 흐름 | 언제, 누가 이걸 실행하나? | `Comments/COMMENT_FLOW.md` |
| A | 구조·설계 | 왜 이렇게 나눠서 만들었나? | `Comments/COMMENT_ARCHITECTURE.md` |
| D | 상태·데이터 | 이 값은 어디서 바뀌고 어떤 규칙을 지켜야 하나? | `Comments/COMMENT_DATA.md` |
| L | 로직·계산 | 이 식이나 조건은 무엇을 계산하나? | `Comments/COMMENT_LOGIC.md` |
| O | 성능·예외 처리 | 왜 일부러 이렇게 (특이하게) 짰나? | `Comments/COMMENT_OPTIMIZATION.md` |
| V | 변수 | 이 변수는 무엇을 나타내고 어디에 쓰이나? | `Comments/COMMENT_VARIABLE.md` |

### 번호 형식
- `카테고리 약자 1글자` + `-` + `세 자리 숫자` (예: `F-001`, `V-012`)
- 각 주석 파일 안에서 001부터 순서대로 매기고, 한 번 쓴 번호는 바꾸거나 재사용하지 않는다.

### 주석 파일 작성 형식

```


F-001
---
[파일명 > 클래스 > 함수]
주석 내용


```

### 코드에 번호 적기

```csharp
// F-001
public event Action OnPlayerDied;

float invincibleTime = 0.5f; // V-001
```

## 사용 방법

1. 사용하는 AI 도구의 규칙 파일(`CLAUDE.md`, `.cursorrules` 등)에 이 파일의 내용을 넣거나, 이 파일을 참조하도록 적는다.
2. 프로젝트 루트에 `Comments/` 폴더를 만든다. (없으면 AI가 규칙에 따라 만든다)
3. AI에게 코드를 요청하면 규칙에 맞춰 코드 주석과 주석 파일이 함께 작성된다.
